# Shipping Tracker (demo)

One searchable view of outbound FedEx and UPS shipments, built from the carriers' daily shipment reports, so anyone can answer "did it ship, and where is it?" without digging through emails.

This is a demo copy. Every customer, contact, PO, order and tracking number here is sample data, so the tracking links won't find a real package.

## What it does
- Search across customer, tracking number, PO, item, order number and city
- Filter by carrier and ship date, or jump to the latest ship day or last 7 ship days
- Daily totals, sortable columns, and tracking numbers that link to the carrier's tracking page
- Flags voided labels

## Run it
Open index.html in a browser.
